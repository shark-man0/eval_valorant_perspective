# 独立評価の採点基準（事前固定）

full_match_6 の QUALIFICATION を開封する前に、採点の方法をここで固定します。手順と定数は `valorant_ai_coach.temporal.independent_scoring` の `PROTOCOL` にあり、解析コードと同じコードダイジェストで計画ファイルに縛られます。開封後に変えると、`execute` が実行を拒否します。

## 対象

- QUALIFICATION の5試合だけを開封して評価します。
- FINAL_HOLDOUT の3試合は開封しません。
- 解析の設定は、承認済みの共通タイムライン（#150・#151）のものに固定します（`FROZEN_OPTIONS`）。評価中に閾値や認識器は変えません。

## 正解ラベル

正解は人手で付けます。ラベルを付ける人には、予測を見せません。

### フレームの正解

- 試合ごとに30秒を選びます。選び方は録画IDと録画の長さだけで決まり、予測には依存しません（`frame_seconds`）。
- 選んだ秒 s について、s + 0.5 秒のフレームを1枚切り出します。5試合で150枚です。
- 1枚ごとに次のラベルを付けます。

| 項目 | ラベル |
| --- | --- |
| Round | BUY、ACTIVE、ENDED、INTERMISSION、OUT_OF_ROUND（ロード、エージェント選択、メニュー、試合終了後の画面）、UNSURE |
| Life | ALIVE、DOWNED、DEAD、NA（本人の状態が定まらない画面）、UNSURE |
| Camera | SELF、SPECTATOR、REMOTE、NA、UNSURE |

### Round 境界の正解

- 試合ごとに6ラウンドを選びます。録画IDだけで決まる順番（1〜40の並べ替え）から、実際に行われたラウンド番号を先頭から6つ取ります。
- 選んだラウンドの開始と終了について、おおよその時刻を記入してもらいます。その前後6秒の1秒ごとのフレームを切り出し、新しい状態が最初に映っている秒を選んでもらいます。
  - 開始：購入フェーズが終わり、ラウンドが始まった（ACTIVE）最初の秒。
  - 終了：ラウンドの勝敗が決まり、終了表示（ENDED）が出た最初の秒。
- 5試合で30ラウンド、60境界です。

## 指標

### フレーム（Round・Life・Camera ごと）

正解ラベルが BUY などの確定した値のフレームを採点します。UNSURE は除きます。予測が正解と同じなら正答、違えば誤答、UNKNOWN なら棄権です。

| 指標 | 定義 |
| --- | --- |
| 正答率 | 正答 ÷ 採点枚数 |
| 誤判定率 | 誤答 ÷ 採点枚数 |
| 取得率 | （正答＋誤答）÷ 採点枚数。UNKNOWN でない値を出した割合 |
| 答えたときの正答率 | 正答 ÷（正答＋誤答） |

- 正答率と誤判定率には、Wilson 法の95%信頼区間を付けます。
- 正解が OUT_OF_ROUND・NA のフレームは別に数えます。ここで確定した値を出した場合は、誤った主張として報告します。
- フレームとは別に、全秒に対する取得率（UNKNOWN でない秒の割合）も報告します。

### Round 境界

- 正解の秒 g は、s + 0.5 秒のフレームで新しい状態が最初に映った秒です。したがって真の切り替わりは [g − 0.5, g + 0.5] にあります。
- 予測の境界候補 [lower, upper] のうち、中心が g から15秒以内で最も近いものを対応させます。なければ検出漏れです。
- 誤差は、候補が [g − 0.5, g + 0.5] と重なれば0秒、重ならなければその隙間の秒数です。
- 検出率、候補内の件数、1秒以内・2秒以内の件数、誤差の中央値と最大値、候補の幅の中央値を報告します。

## 手順

1. 採点基準（この文書と `PROTOCOL`）、認識器、設定を main で固定し、コードダイジェストを記録する。
2. QUALIFICATION の5試合を `recordings open --purpose qualification` で開封する。
3. `independent_evaluation prepare` で計画を作る。コードダイジェストが手順1の記録と一致することを確かめる。
4. `independent_evaluation execute` で解析する。
5. 解析が終わってから `independent_scoring frame-kit` と `boundary-kit` で正解付けの素材を作り、人手でラベルを付ける。
6. `independent_scoring score` で採点する。
7. 結果を報告する。正式な資格付けは統括が判断する。

採点結果も `formal_qualification: NOT_GRANTED`、`formal_outputs: 0` のままです。
