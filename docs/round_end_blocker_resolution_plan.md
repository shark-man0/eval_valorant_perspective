## Single permitted hypothesis and stop rule

Hypothesis: **a positively witnessed Spike→Decimal representation change may corroborate an actually observed adjacent +1 score transition, under its own source-bound temporal contract**. Numeric countdown behavior stays unchanged. This is a proposed research contract, not a new production End backend.

The proposal must explicitly model numeric/Spike/decimal/unknown/occluded clock; accepted score and consecutive stability; complete/partial/stale caption; source breaks; contradictory UI; an actual active Start; and an immutable confirmation deadline. Boundary remains the first accepted score-update frame. Clock/result witnesses are corroboration, never permission to invent a prior score or move the boundary. Preserve the one-second horizon, integer PTS/timebase, source/epoch binding, repeated-raster/gap rejection, unknown values and no player-owned facts. Keep duration sentinel and local fragment numbering out of event semantics.

Stages, limited to this family:

1. Freeze the contract from existing observations and synthetic examples before testing it. No reader/ROI/reference retuning.
2. Run synthetic positive and negatives: numeric-only, Spike-only, decimal-only, score-only, clock-only, incomplete/stale result, buy phase, spectator/unknown, source break, PTS gap, repeated raster, duplicate End, fragment without actual Start. No negative may become Formal End.
3. Deterministically replay saved rows with exact code/profile/prototype/hash bindings. Historical mixed-component diagnostics must remain labelled as such. An active Start cannot be injected into real source fragments merely to make replay succeed.
4. If source-backed feasibility exists, verify whether suitable independently preallocated positive/negative temporal data actually exist. A pool name or a new video filename is insufficient.
5. **If independent temporal evidence and complete release prerequisites are missing, stop as unqualified.** Do not acquire/reanalyse hundreds of frames to manufacture apparent qualification. No production default, Formal End release or new Full E2E.

## Independent evidence currently missing

No complete, independently reviewed Start→End dataset is currently established for the proposed typed contract. Existing supplemental episodes have been source-reviewed/predicted; they are not blind again. The published PTS inventory is nonexhaustive and does not certify unlisted frames as unseen. Later unviewed candidate intervals may still exist, so a new video is not automatically required, but their independence cannot be asserted from the inventory alone.

Before any future evaluation, obtain:

- source SHA256, untouched original PTS/timebase, decoder epoch/cadence and source-continuity/break review;
- event-level training/holdout/negative allocation and exposure review, fixed before predictions;
- independent last-old/first-new score bracket, last-old/first-new clock-type bracket, first complete/last incomplete caption bracket and confirmation semantics;
- actual same-source active Start and complete context when claiming lifecycle, rather than an injected Start or geometry reference;
- natural negatives for ordinary countdown/Spike/decimal display, stale caption, menu/buy/spectator contexts and discontinuity, with the tested observation range stated;
- current-code/profile/asset fingerprints and an explicit budget/stop rule before any new targeted execution.

At minimum, two distinct unseen Spike→Decimal positive episodes (different result outcomes where available) are an engineering replication check, not a statistical accuracy guarantee. Each distinct negative threat class needs explicit coverage; repeated frames from one episode do not increase the independent event count. Synthetic negatives remain necessary but cannot replace real-data false-positive evaluation. An independent curator must confirm actual exposure and label provenance. #19 match_002 remains independent and is not used for development.
