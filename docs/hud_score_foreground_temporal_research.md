## Current pixels

`score_foreground_recovery.recover_score` selects neutral bright source pixels
(each channel >=200, channel range <=35) without filling missing native pixels.
The strict ten-class matcher, layout, leading-zero and border rejection still
apply. Existing normalization resamples pixels; that is not new source evidence.
An existing Reader value is never overwritten by this offline fallback.

Fragments with overlapping x intervals are inspected as unions of original
foreground pixels. No closing, dilation bridge or inpainting invents strokes.
Grouping yielded no extra supported read, so it remains diagnostic and cannot

## Reject-only history

`ScoreReadHistory` separates current direct text from the previous direct
observation. Hidden/unread current frames remain UNKNOWN. Gaps, duplicate or
reversed PTS, source/epoch/timebase changes, explicit/unknown cuts and missing
continuity reset association. Sparse epochs are not stitched. Mechanical native
adjacency does not prove visual continuity; uncertainty remains in output.

Recovery requires current pixels, current Geometry and an immediately preceding
admitted direct observation of the same value. No previous value is copied into
the current frame. In measured real contexts this conservative gate adds no read;
missing neighboring Geometry is not inherited from a center frame.

A shorter suffix plus neutral-foreground loss below3/4 of the prior two-digit
field flags possible digit loss. The literal stays in the record; admission is
UNKNOWN until a full-length observation or source reset. This is uncertainty,
not confirmed occlusion. Legitimate HUD/side-score transitions can be ambiguous
too, so normal-transition regression evidence is required before adoption.

Seven controlled derivatives hid the left half of existing two-digit crops.
Baseline and foreground-only paths proposed five numbers; the temporal simulation
rejected those five. These are synthetic controls, not real occlusion GT or a
population error rate. Partial first frames and non-suffix ambiguity remain open.
